# Dev.to Blog Series Outline

## Series: Building YAAM — A Job Application Tracker from Scratch

Document the full journey, from the initial idea to a live product. Target audience: developers who want to build side projects and job seekers who might become users.

## Planned Posts

1. **Why I built yet another job application tracker** — motivation, the gap in existing tools, the Swiss market angle
2. **Business analysis before a single line of code** — how to scope an MVP, what a lean business plan looks like for a solo dev
3. **Choosing the stack: Angular + .NET + provider-agnostic AI** — trade-offs, why not the usual suspects
4. **Docs-first development** — why I wrote the architecture before scaffolding the project
5. **Building a CV parser with a swappable AI backend** — Ollama locally, API in prod
6. **Cover letter generation that doesn't feel generic** — using structured profile data for grounded output
7. **Shipping it: domain, CD, and the first real user** — deployment on Infomaniak, CI/CD with GitHub Actions
8. **Pricing a side project: freemium vs pay-as-you-go** — what I learned and what I'd do differently

## Format

- Each post: 800–1500 words, code snippets where relevant
- Cross-post to personal blog (if created)
- Include honest numbers (time spent, costs, users)

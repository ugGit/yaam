# Pricing Model

## Options Under Consideration

### Option A: Subscription
- Monthly/annual flat fee for all features
- Predictable revenue, simpler UX
- Risk: users churn after job search ends

### Option B: Pay-as-you-go
- Charge per AI operation (cover letter generation, CV parse, etc.)
- Aligns cost with value delivered
- Risk: friction at usage time, harder to predict revenue

### Option C: Freemium (working assumption)
- Free: core tracking, manual CV/application entry, basic reminders
- Paid: AI features (cover letter generation, profile refinement, smart matching)
- Best balance for side project: free tier drives growth, paid tier monetizes power users
